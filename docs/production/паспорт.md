## Runtime и зависимости

Чистая статика React/Vite без backend, DB, secrets и persistent state.
Production собирается в multi-stage Docker image и обслуживается nginx через
Dockploy/Traefik. Внешняя runtime-зависимость — DNS Spaceship. Шрифты Forum и
Roboto хранятся локально как OFL-licensed WOFF2 subsets.

## Release

1. Собрать `site/dist` на Node.js 20.19+ или 22.12+.
2. Пройти test, lint, build и secret scan.
3. Запушить exact revision в `main`.
4. Собрать и развернуть `deploy/docker-compose.dokploy.yml` в compose `faska-art`.
5. Проверить container health, Traefik route, HTTP, HTTPS, desktop, viewport
   390×844, overflow и console errors.

## Backup и rollback

- Source backup: история `main`.
- Release backup: предыдущая успешная Docker/Dockploy revision.
- Внешний rollback: `https://larkinmd7.github.io/larkinmd7-content/alina-ceramics/` сохраняется без изменений.
- Application rollback: redeploy предыдущего commit/image внутри compose
  `faska-art`; соседние compose проекта `web-sites` не менять.
- DNS rollback: вернуть предыдущие зафиксированные записи. До Timeweb домен
  кратковременно указывал на GitHub Pages A-records; GitHub Pages для repository
  отключён.
