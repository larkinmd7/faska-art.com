# faska-art.com

## Владельцы и маршрут

- Product owner: Алина.
- Technical owner: Михаил Ларькин.
- Production URL: `https://faska-art.com`.
- Repository: `https://github.com/larkinmd7/faska-art.com`.
- Pages source: branch `gh-pages`, path `/`.
- DNS provider: Spaceship.

## Runtime и зависимости

Чистая статика React/Vite без backend, DB, secrets и persistent state.
Production зависит от GitHub Pages, DNS Spaceship и публичных Google Fonts.

## Release

1. Собрать `site/dist` на Node.js 20.19+ или 22.12+.
2. Пройти test, lint, build и secret scan.
3. Опубликовать точное содержимое `dist/` в `gh-pages`.
4. Проверить HTTP, HTTPS, desktop, viewport 390×844, overflow и console errors.

## Backup и rollback

- Source backup: история `main`.
- Release backup: предыдущий commit `gh-pages`.
- Внешний rollback: `https://larkinmd7.github.io/larkinmd7-content/alina-ceramics/` сохраняется без изменений.
- DNS rollback: вернуть зафиксированные до миграции Spaceship records. На момент старта домен использует дефолтные parking A-records.

## Health и smoke

- `https://faska-art.com/` → HTTP 200;
- HTML ссылается на существующие hashed JS/CSS assets;
- favicon и все работы из `site/public/images/` отвечают 200;
- `document.documentElement.scrollWidth === window.innerWidth` на mobile;
- console errors отсутствуют.
