## 5. Анализ оборудования (по фото студии)

### 5.0 Визуальный анализ помещений

**Учебный зал (~60-80 м², высота потолков ~3 м):**
- Ремонт хороший, чистый. Стены бежевые, ровные
- Потолок подвесной Armstrong, белый. LED-панели, яркое освещение
- Пол — светлый линолеум/наливной
- Зонирование шторами (бежевые, от потолка до пола) — зона ручной лепки / зона гончарных кругов
- На стенах — декоративные тарелки, информационные стенды, часы
- 4-5 гончарных кругов **Nidec** (синие корпуса, жёлтые поддоны) у окон
- 2-3 слэб-роллера (раскатные машины для глины) — проф. оборудование
- Длинные белые столы для ручной лепки в центре
- Металлические стеллажи (4-5 полок) с изделиями на сушке

**Цех обжига (~40-60 м², коридорного типа ~10-15м × 3-4м):**
- Технический ремонт: стены серые/бетонные без отделки
- Потолок технический — видны трубы, вентиляционные короба
- **Мощная вытяжная система** — металлические зонты над печами
- **3-4 печи** разного размера: среднего и большого (диаметр 60-80 см, высота 80-100 см)
- 1 большая камерная печь (фронтальная загрузка, камера ~50×50×60 см, спирали нагрева видны)
- Покрасочная камера с **краскопультом для глазури** — проф. оборудование
- Стеллажи плотно заполнены изделиями на разных стадиях (сырец, бисквит, глазурованные)

**Входная зона / ресепшн:**
- Белая стойка администратора, логотип "Академия Керамики"
- Стеклянные витрины с готовыми изделиями (магазин/выставка)
- Декор: цветные помпоны на потолке, горшок с цветами

## 12. Выводы

### Бизнес-модель

1. **Маржинальность по материалам — 95%+** — глина стоит копейки (10-26 ₽/кг), основные расходы — ФОТ и аренда
2. **ФОТ — 60-70% всех расходов** — типично для сферы услуг/образования
3. **Аренда — 15-20% расходов** — критический фактор для прибыльности
4. **Ёмкость 1 локации — потолок ~17 млн/год** (доказано в 2022)
5. **Устойчивый уровень — 10-12 млн/год** (2019-2021)

### Ключевые рычаги

| Рычаг | Влияние на прибыль |
|-------|--------------------|
| +1 группа детей (5 чел) | +30 750 ₽/мес (+369 тыс/год) |
| +1 МК взрослых/нед | +50 700 ₽/мес (+608 тыс/год) |
| +10% к ценам | +90-120 тыс/мес |
| -1 преподаватель | +60-80 тыс/мес (с налогами) |
| 2-я локация | ×1.5-2.0 выручка, +50-70% расходов |

### Риски

- Единственная локация — нет диверсификации
- Тренд выручки вниз 2 года подряд
- Конкуренция растёт ("Гончарная №1" = 11 точек)
- Проедание капитала (7,8 млн осталось → ~1.5 года при текущих убытках)

### Возможности

- Онлайн-курсы — маржинальность ~90%, масштабируемо
- Образовательная лицензия — уникальное преимущество (маткапитал, госпрограммы)
- Корпоративный сегмент — высокий чек (27-72 тыс за мероприятие)
- Франшиза — 12 лет экспертизы, бренд с 5.0 рейтингом

### Северная Звезда

Если бы студия работала на уровне 2022 (16,9 млн выручки) при текущих расходах:
- Выручка: 1,4 млн/мес
- Расходы: ~1,0-1,2 млн/мес
- Прибыль: **+200-400 тыс/мес** (2,4-4,8 млн/год)

Для выхода на этот уровень нужно: загрузка 12-14 групп детей + 8-10 МК взрослых/нед + активные корпоративы.
