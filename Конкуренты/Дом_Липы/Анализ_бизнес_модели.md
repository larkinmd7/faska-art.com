## 2. Бизнес-модель: потоки доходов

«Дом Липы» — **многопродуктовый творческий бизнес**. Не одна студия, а экосистема из 4 направлений:

| Направление | Продукт | Формат |
|-------------|---------|--------|
| **1. Мастер-классы** | Открытые МК из афиши | B2C, регулярно |
| **2. Арт-вечеринки** | Частные события (корпоративы, ДР, девичники) | B2B + B2C |
| **3. Аренда студий** | 6 студий на 2 локациях | B2B + B2C |
| **4. Загородные выезды** | 2-3 дня на природе + творческая программа | B2C, сезонно |
| **5. Глэмпинг** | Дача Липы в Тверской области | B2C, сезон июнь-сент |

| Рентабельность | -88% | +2.7% | +29.4% |

> **Интерпретация:**
> - **Пессимистичный** — ситуация убытка (первый год или кризис). Бизнес выживает на резервах или личных вложениях.
> - **Базовый** — выход почти в ноль. Это типично для Moscow-based creative space: аренда съедает маржу.
> - **Оптимистичный** — при полной загрузке двух локаций + активный сезон глэмпинга = хорошая прибыль.

### 6.1 Точка безубыточности

```
Постоянные расходы = 566 000 (аренда) + 350 000 (ФОТ) + 60 000 (прочие) = 976 000 ₽/мес

Маржинальность выручки ≈ 60% (после вычета переменных: мастера, материалы, налог)

Точка БУ = 976 000 / 0.60 = 1 627 000 ₽/мес выручки
```

**Вывод:** Нужно набирать **~1.6 млн ₽/мес выручки** для выхода в ноль. При базовом сценарии (1.9 млн ₽) — чуть выше порога.

---

### 6.2 Верификация по факту ООО/ИП

Финансовая отчётность ИП не является публичной. Косвенные индикаторы:

| Индикатор | Оценка |
|-----------|--------|
| 273 отзыва на Яндекс Картах | Высокий поток → ближе к базовому/оптим. |
| 46 000 подписчиков Instagram | Хороший охват → стабильный спрос |
| 2 локации в Москве | Расширение = рост выручки |
| ИП с 2022, бизнес с 2019 | 6 лет на рынке = устойчивость |
| Реестр МСП: микропредприятие | Выручка скорее всего < 120 млн ₽/год |

**Вывод:** Бизнес, вероятно, работает в диапазоне **15–30 млн ₽/год** (ближе к базовому сценарию).

## 12. Unit Economics

| Метрика | Формула | Значение (базовый) |
|---------|---------|-------------------|
| **Средний чек (AOV)** | Выручка / транзакции | ~3 000 ₽ (МК) / ~55 000 ₽ (выезд) |
| **LTV** | Средний чек × частота × срок | ~20 000–60 000 ₽ (лояльный клиент, 3 года) |
| **CAC** | Маркетинг / новые клиенты | ~500–1 500 ₽ (органика) |
| **LTV:CAC** | | **13:1–40:1** — отлично |
| **Gross Margin (МК)** | (Чек - Мастер - Материалы) / Чек | **~40%** |
| **Gross Margin (Аренда)** | (Аренда - Переменные) / Аренда | **~85%** |
| **EBITDA Margin** | EBITDA / Выручка | **~5–15%** (базовый) |
| **Выручка/м²** | 1 902 000 ₽ / 253 м² | **7 520 ₽/м²/мес** |
| **ФОТ% от выручки** | 603 000 / 1 902 000 | **31.7%** — норма |
| **Аренда% от выручки** | 566 000 / 1 902 000 | **29.8%** — немного высоко |

> **Аренда 29.8%** — нормативный порог 15-20%. Значит бизнес зависит от роста выручки (больше МК и арендных событий при той же аренде).

## 14. Выводы

### Бизнес-модель (ключевые метрики)

| Параметр | Значение |
|----------|---------|
| Тип | Creative space + event + glamping |
| Основной двигатель | Instagram 46K + сарафанное радио |
| Главный риск | Аренда ~30% выручки при тонкой марже |
| Фаза | Зрелость: 6+ лет, расширение (2-я локация) |
| Масштаб | Выручка ~15–25 млн ₽/год (оценка) |
| Прибыль | ~0.5–3 млн ₽/год (базовый) |

### Рычаги (что влияет на прибыль)

1. **Загрузка студий** — аренда фиксированная, каждый новый МК/событие = почти чистая прибыль
2. **Арт-вечеринки** — самый высокомаржинальный поток (цена 4500-6000 ₽/чел)
3. **Загородные выезды** — высокий чек при низких переменных затратах
4. **Глэмпинг** — хорошая маржа, но сезонный и капиталоёмкий

### Риски

- **Аренда** — при снижении выручки на 20% → убыток
- **Owner dependency** — бизнес держится на личности Ани/Кати, аудитории Instagram
- **Сезонность** — лето = пик, зима = потенциально слабее
- **Монозависимость** от Instagram (при блокировке — потеря канала)

### Возможности

1. **YouTube** — канал с МК, процессом, закулисьем выездов → SEO-трафик на годы
2. **2ГИС** — 7 отзывов при 273 на Яндексе — огромная дыра. Попросить лояльных клиентов → +бронирования
3. **B2B корпоративы** — тимбилдинги = высокий чек, можно масштабировать без роста аренды
4. **Зимние выезды** — снежные тематические выезды на дачу (уже есть купола с кондиционером)

### Рекомендации (что бы мы сделали иначе)

1. **YouTube-канал** — завести немедленно. 46K Instagram = 5-10K YouTube в первый год органически
2. **2ГИС** — поднять до 50+ отзывов за 2-3 месяца = +20-30% брони от локального поиска
3. **Email/Telegram-база** — текущие клиенты не собираются в канал. Сарафан → воронка
4. **Зимние выезды** — глэмпинг простаивает 8 месяцев. Зимние тематические заезды = х2 к выручке дачи
5. **Franchise-light** — продавать методологию другим городам (Казань, СПб, Екб) как лицензию без открытия своего офиса
