# Обновление портфолио Faska Art из Instagram

Дата: 2026-08-13
Статус: согласованная концепция, ожидает подтверждения письменной спецификации

## Цель

Усилить сайт Алины для обращения к дизайнерам интерьеров: показать свежие, визуально сильные предметы, которые легко представить в квартире, ресторане или другом интерьерном проекте. Одновременно исправить ссылку Instagram на официальный профиль [@faska.art](https://www.instagram.com/faska.art).

## Источник и происхождение материалов

- Единственный источник новых фотографий — официальный Instagram Алины `@faska.art`.
- Скачиваются оригинальные изображения публикаций в максимально доступном разрешении, без интерфейса Instagram, подписей и скриншотов.
- Для каждой добавленной работы сохраняется URL исходной публикации в отдельном manifest-файле рядом с данными портфолио.
- Если оригинал нельзя получить в достаточном качестве, фотография пропускается.

Проверенные публикации-кандидаты:

- Черничная серия, 21 июля 2026: <https://www.instagram.com/p/DbEIZmijf48/>
  - крупный кувшин/ваза с двумя ручками — главный кандидат на обложку;
  - композиция серии — дополнительный интерьерный кадр;
  - чашка крупным планом — кандидат для существующей категории чашек;
  - кашпо с растением — кандидат для интерьерной категории;
  - кадр с серьгами и размытым объектом исключается.
- Чёрное кашпо с мотыльком, 26 марта 2026: <https://www.instagram.com/p/DWWzgM4jVpU/>
  - выбрать один наиболее резкий кадр без почти идентичного дубля.
- Серия чашек Tattoo Theme, 13 июня 2026: <https://www.instagram.com/p/DZifhefkYJb/>
  - обложка с наложенным текстом исключается;
  - чистые предметные кадры из карусели допускаются после проверки качества.
- Остальные свежие публикации `@faska.art` просматриваются только для добора до 8–10 сильных фотографий по тем же критериям.

## Критерии отбора

В итоговую подборку входят 8–10 фотографий, где:

- предмет резкий, хорошо освещён и занимает заметную часть кадра;
- фактура, форма и ручная работа читаются без увеличения;
- кадр помогает представить изделие в интерьере;
- отсутствуют текстовые плашки, интерфейс Instagram и водяные знаки;
- нет личных фотографий, кадров процесса, размытых объектов и повторов;
- Reels не используются; допускаются только самостоятельные оригинальные фотографии из публикаций-каруселей.

Из близких кадров одной работы выбирается один лучший. Количество не важнее качества: если строгий отбор проходят меньше восьми фотографий, публикуется меньшая подборка.

## Структура сайта

### Новая категория

Добавить категорию `Интерьерная керамика` со slug `interernaya-keramika`. В неё входят крупные и декоративные предметы: вазы, кувшины, кашпо, композиции и другие объекты, подходящие для интерьерных проектов.

- Обложка категории — крупный кувшин/ваза из черничной серии, если скачанный оригинал проходит проверку качества.
- Основная подборка категории — 6–8 разных предметов или композиций.
- Чистые предметные фотографии чашек можно добавить в существующую категорию `Чашки`.
- Одна фотография не дублируется в нескольких категориях.

### Контакты

В `src/data.ts` заменить неверную ссылку Instagram на:

`https://www.instagram.com/faska.art`

Ссылка должна работать в футере и на странице контактов вместе с Telegram.

## Файлы и обработка изображений

- Новые оригиналы хранятся в `public/images/instagram-2026/` с понятными латинскими именами.
- Веб-версии конвертируются в WebP с сохранением пропорций; максимальная сторона — 1800 px, качество — 84.
- Кадрирование допускается только для удаления пустых краёв, если объект остаётся целиком и композиция улучшается.
- Мозаичная галерея сохраняет естественное соотношение сторон фотографии.
- Manifest содержит имя локального файла, URL поста, дату публикации и краткое описание предмета.

## Изменения в коде

1. Скачать и проверить кандидатов из официального Instagram.
2. Отобрать 8–10 лучших предметных фотографий и подготовить WebP.
3. Добавить manifest происхождения материалов.
4. Дополнить категории и работы в `src/data.ts`.
5. Исправить Instagram URL и тест ожидаемой ссылки.
6. Проверить галерею, карточки категорий, lightbox, футер и страницу контактов.

Существующая визуальная система сайта сохраняется: новая подборка должна выглядеть частью текущего портфолио, без отдельного редизайна.

## Обработка ошибок

- Недоступный оригинал или недостаточное разрешение: кандидат исключается.
- Совпадающий хеш изображения или визуальный дубль: сохраняется один лучший кадр.
- Отсутствующий локальный файл, битая ссылка на изображение или повторяющийся ID работы: проверка завершается ошибкой до публикации.
- Неверный формат или ориентация изображения исправляются на этапе подготовки, без растягивания.

## Проверка результата

- Автоматическая проверка наличия новой категории, уникальности работ и существования всех файлов изображений.
- Тест точного Instagram URL `https://www.instagram.com/faska.art`.
- Production build и проверка изменённых файлов линтером; известная старая ошибка линтера в `Gallery.tsx` фиксируется отдельно и не маскирует новые ошибки.
- Локальная визуальная проверка Playwright на desktop и mobile.
- После публикации: проверка live-страницы на ширине 390 px, отсутствие горизонтального скролла, ошибок консоли и битых изображений.

## Критерии готовности

- На сайте появилась категория `Интерьерная керамика` с сильной предметной обложкой.
- Добавлены до 8–10 новых качественных фотографий без дублей, плашек и интерфейса Instagram.
- Для каждой фотографии сохранена ссылка на исходный пост.
- Правильный Instagram открывается из футера и контактов.
- Категории, галерея и lightbox работают на телефоне и компьютере.
- Обновление опубликовано на действующем GitHub Pages-сайте.
